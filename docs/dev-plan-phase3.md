# 第三阶段开发计划：预测模型升级、准则条文库、动态数据展示

> 约束不变：全部数值由 `src/api/services.py` 产出。第三方库可以装，只有大模型调用需要走内网；
> 本阶段的新模型仍用 numpy / scipy 自研（零依赖部署、每一步讲得清），正确性靠定义对拍、数值梯度校验与成熟库交叉比对。

## 1. 预测模型升级

### 1.1 精确 TreeSHAP（`src/models/treeshap.py`）

- 直接读取 sklearn HistGradientBoosting 的树结构，按路径依赖口径计算精确 Shapley 值：
  每个叶子上把路径特征的"覆盖比例 z"与"是否沿该路径 o"写成多项式，组合权重 |S|!(n−|S|−1)!/n! 逐项累加。
- 可加性：基准值 + Σ SHAP = 模型原始输出（逐井校验）；测试里再用穷举子集的 Shapley 定义逐位对拍。
- 单井解释替换原"特征消融"；训练时对测试集算全局 SHAP，供蜂群图。

### 1.2 早期序列模型（`src/models/seq_model.py`）

- 输入：投产后前 90 天逐日序列（日产、开井、相对井口压力、含水、气油比、累产）+ 静态与完井参数。
- 结构：三层膨胀卷积（膨胀率 1/2/4，残差）→ 均值与最大池化 → 拼接表格特征 → 全连接 → 每个目标输出 P10/P50/P90
  （P10、P90 以 softplus 间隔保证不交叉）；分位数损失，Adam，早停，多种子集成。反向传播手写并做梯度数值校验。
- 时间归因：积分梯度（Integrated Gradients），给出"前 90 天里哪几天、哪个通道"决定了预测。

### 1.3 融合与校准

- 校准集按井号对半分：A 半在 {0, .25, .5, .75, 1} 中为每个目标选梯度提升与序列模型的融合权重（分位数损失最小），
  B 半做保形校准 —— 选权重与校准不用同一批井。
- 测试集并排报告：梯度提升、序列模型、融合三者的 MAE 与覆盖率，结论由数据决定。

### 1.4 带物理约束的递减模型（`src/reserves/physics_dca.py`）

- 流态：线性流（等效 b = 2，q ∝ t^−1/2）→ 边界控制流（b ≤ 1）→ 终端指数递减；衔接点产量与递减率连续。
- 约束：b 上界 1（边界控制流物理上限）、终端递减率、EUR ≤ 容积法地质储量 × 采收率上限（区块经验上限放宽）、
  对 b 与线性流结束时间的弱先验（历史越短先验权重越大）。
- 诊断：产量–时间双对数斜率（−1/2 → 变陡）、规整化压力 RNP–物质平衡时间 MBT 双对数。
- 回测（`python -m src.cli eval-dca`）：老井截取峰后 6 / 12 / 24 个月拟合，对比经验 Arps 与物理约束模型
  对未来 12 个月累产（实测）与 EUR（合成真值）的误差，以及高估比例（SEC 口径最关心）。

## 2. 准则条文库

- 原文：eCFR 2025-01-01 版 17 CFR 210.4-10（Regulation S-X Rule 4-10）与 17 CFR 229.1201–1208（Regulation S-K Items 1201–1208），
  原始 XML 存 `data/standards/raw/`，`python -m src.cli build-standards [--fetch]` 生成条款级语料。
- 切分到段落层级：`[Rule 4-10(a)(31)(ii)]`、`[Item 1203(b)]`；每条保留官方英文原文、CFR 全称、上级条款。
- 中文"要点"为非官方说明（`data/standards/notes_zh.yaml`），并提供中英术语表做检索扩展。
- 规则引擎、检查清单、智能体引用改为精确条款：合理确定性 → (a)(24)，可靠技术 → (a)(25)，价格 → (a)(22)(v)，
  经济可采 → (a)(10)，已开发 → (a)(6)，PUD 五年规则 → (a)(31)(ii)，PUD 披露 → Item 1203。
- 接口：条款检索、按条款号取原文；前端新增"准则条文"页，检查清单与问答里的条款号点开即看原文。

## 4. 验证

TreeSHAP 与穷举 Shapley 对拍、可加性；TCN 梯度数值校验、玩具数据可学习；物理约束模型 b ≤ 1、流态衔接连续、EUR 上限生效；

## 5. 实施结果（2026-09-16）

| 项 | 结果 |
| --- | --- |
| 精确 TreeSHAP | 与穷举 Shapley 逐位一致（< 1e-9）；真实模型包可加性误差 < 1e-10；150 口井 × 5 目标约 0.5 秒（numba） |
| 序列模型 | 3 层膨胀卷积（1/2/4）+ 均值/最大池化 + 表格特征，3 个种子；反向传播数值校验相对误差 < 1e-7；训练约 10 秒 |
| 融合 | 权重 {见油 0.25, 达峰时间 0.75, 达峰产量 0.5, 达峰压力 0.5, EUR 0.25}；EUR MAE 1367 → 1195（−12.5%），达峰产量 1.14 → 1.01，见油时间 0.75 → 0.89（变差，如实保留） |
| 物理约束递减 | 峰后 6 个月：EUR 中位误差 11.3% → 7.9%，高估 > 20% 的井 22.8% → 11.7%；12 / 24 个月经验 Arps 更准 → 只做复核 |
| 条文库 | eCFR 2025-01-01 原文 228 段（Rule 4-10 133 段、Items 1201–1208 95 段），检查清单与规则引擎改引 (a)(10)/(a)(6)(i)/(a)(22)(v)/(a)(24)/(a)(25)/(a)(31)(ii) |
| 动态展示 | 总览生产动态回放、全局 SHAP 蜂群、模型族对比；单井 SHAP 瀑布、区间对比、时间归因热力图；储量页递减诊断三视图；准则条文页；评测页递减回测表 |

与计划的偏差：初版物理约束模型把线性流结束时间的先验中心放在 18 个月、先验权重按 √(12/n) 缩放，数据项未按观测噪声标准化，
先验压过数据，回测 EUR 偏高 25%–33%；改为按 σ 标准化的最大后验、宽先验中心 3 个月、并加入同区块类比先验后才得到上表。


## 6. 补弱点：区块迁移、EUR 覆盖率、失败样例（2026-09-16）

### 6.1 动手前的诊断（只看输入与校准集，不看测试标签）

| 诊断 | 结果 | 结论 |
| --- | --- | --- |
| 分块留出测试井的输入 | 156 / 156 口来自没见过的区块；邻井距离特征 100% 超出训练 1–99% 分位；最大尺度偏离中位 7.7（时间外推测试井 1.1） | 根因是神经网络对训练范围外的输入线性外推，不是"权重选错" → 原计划的"按区块交叉选权重"不对症，改为逐井漂移守卫 |
| 被留出区块 one-hot 列的网络权重 | 权重衰减后约 0 | 排除"未训练权重引入随机偏移"的猜测 |
| 校准集 EUR 一致性分数 vs 投产时间 | Spearman −0.11（p = 0.28），早 / 晚半 80% 分位 0.43 / 0.41 | 没有时间漂移证据 → 不做近期加权保形 |
| 校准集 EUR 一致性分数 vs 预测规模 | 小 / 大井半 80% 分位 0.45 / 0.41 | 分组没有依据 → 不做按规模分组保形 |
| 保形样本量 | 旧做法只有 45 口井参与保形校准 | 唯一有依据的改进：交叉拟合，91 口全用 |

### 6.2 改动

- `src/models/drift.py`：输入漂移守卫（类别没见过 / 连续特征偏离度 > 校准集 99% 分位 → 该井序列权重置 0，区间用梯度提升的保形修正量）；
- `src/models/ensemble.py`：`select_and_crossfit` 交叉拟合；`blend` 支持逐井权重；
- 训练时记录每个目标误差最大的 8 口测试井；智能体评测记录六类问题并区分"按设计追问 / 拒答"；递减回测记录高估最多的井；评测页三块失败样例面板。

### 6.3 结果

| 项 | 改动前 | 改动后 |
| --- | --- | --- |
| 按区块留出 · EUR MAE（梯度提升 691） | 融合 1778 | 线上 **691**（156 / 156 口被守卫识别；不加守卫 1119） |
| 按区块留出 · 见油时间 MAE（梯度提升 0.89） | 融合 6.18 | 线上 **0.89** |
| 时间外推 · EUR 覆盖率（名义 0.80） | 0.64 | **0.78**（漏覆盖 21 口在 P10 以下、3 口在 P90 以上 —— 下侧仍偏乐观） |
| 时间外推 · EUR MAE | 1195 | 1155（不加守卫 1115；守卫标记 6 / 114 口的保险费） |
| 时间外推 · 见油 / 达峰时间 MAE | 0.89 / 29.57 | 0.84 / 30.85（达峰时间权重选到 1.0，不如单用梯度提升 29.56） |

| TreeSHAP 独立验证 | 穷举 Shapley 对拍 | 另加 shap 0.52 TreeExplainer 交叉比对（< 1e-6） |
