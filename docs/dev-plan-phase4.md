# 第四阶段开发计划：真实数据验证与 SEC 披露加分项

> 约束不变：全部数值由 `src/api/services.py` 产出；智能体工具只读；合成真值只供测试与评测；
> 数据库、模型产物、外部下载的数据一律不入库；公开数据的井号、井名、公司名不写进仓库（只出现在本地数据目录）。

## 0. 动手前的审查结论

| 事项 | 现状 | 结论 |
| --- | --- | --- |
| 物理约束递减的验证 | 主合成数据的递减按 Arps 生成，没有线性流段；物理约束模型只在短历史上赢 | 需要两类新证据：带真值、但不偏向任何一种拟合公式的线性流数据；以及真实致密油井 |
| 线性流合成数据怎么造 | 若用 `physics_dca.rate` 造数据，等于让物理约束模型考自己出的题（与"按 Arps 造数据偏向 Arps"同一个毛病） | 用封闭平板恒压解析解（渗流力学经典解：早期 q∝t^-1/2，晚期指数递减）生成，与两种拟合公式都不同；**不改主数据库**，只作为回测队列 |
| NDIC 公开数据 | 北达科他州矿产资源部月度产量表 2018-01 起可下载（每月约 3 MB，含逐井油/水/气、生产天数、层位、经纬度） | 适配器只读油、天数、层位、投产月；井号做不可逆哈希；数据落 `data/raw/ndic/`（已忽略）；真实井没有 EUR 真值，只比未来 12 / 24 个月产量 |
| Item 1203 PUD 披露 | `unit_category_tracking` 已有 PUD 期初/转化/五年移出/新入账/期末、转化率、消化年限；`unit_proved_categories` 有逐井位首次入账、期限、计划钻井、投资 | 不需要新算法：按 Item 1203(a)–(d) 组织成披露草稿，每句的数字取自服务、带条款引用 |
| ASC 932 标准化计量 | SEC 价、吨油净收入、单井操作成本、PDP/PDNP/PUD 数量与 PUD 投资、折现函数都在；缺所得税率 | 所得税率作为明确标注的假设进配置；剖面沿用减值测试的单元级口径（PD 指数剖面、PUD 类型曲线按计划钻井月起算），与减值测试一致 |
| 单元级概率汇总 | 老井有逐井最佳 / 保守剩余可采，但没有逐井误差分布 | 误差分布来自递减回测的相对误差、井间相关来自同区块误差的组内相关；只对误差模型经过验证的老井动态法部分做概率汇总，新井与 PUD 保持确定性相加 |

## 1. 第二档：真实数据验证

1. `src/synth/linear_flow_cohort.py`：平板解生成 300+ 口带真值的月度序列（三个"区域"的特征时间不同，供类比先验），`eval-dca --dataset linear_flow`；
2. `src/ingest/ndic_public.py`：下载、解析、匿名化、选井（Bakken / Three Forks，2018 年后投产、历史 ≥ 36 个月），`eval-dca --dataset ndic`；
3. `src/eval/eval_dca.py` 重构为"数据集 → 井列表 → 统一回测协议"，主合成数据集的结果必须与重构前一致；评测页按数据集切换。

## 2. 第三档：SEC 业务加分项

4. `services.unit_pud_disclosure`：Item 1203(a) 期末 PUD、(b) 重大变化与转化、(c) 转化投资与进展、(d) 五年以上未开发的说明；类别跟踪页"披露草稿"面板 + 报告章节；
5. `finance.standardized_measure` + `services.unit_standardized_measure`：未来现金流入、生产成本、开发成本、所得税、未折现净现金流、10% 折现、标准化计量；两期变动表（销售净额、价格与成本变化、折现回拨、已发生开发成本、数量变化轧差），按构造闭合；
6. `services.unit_probabilistic_reserves`：老井剩余可采的蒙特卡洛聚合（单因子相关），给出单元 / 公司 P90 / P50 / P10 与"逐井低值相加"的差距，并对相关系数做敏感性（0、估计值、1）。

## 3. 验收

每项配测试；主合成数据集的递减回测结果与重构前逐项一致；Item 1203 与标准化计量表的数字均能在服务返回里找到出处；两期变动表闭合；
概率汇总在 ρ=1 时 P90 等于逐井 P90 之和、ρ=0 时显著高于逐井相加；README 与 AGENTS 更新；分项提交。


## 4. 实施结果（第二档 + 第三档第 1 项，2026-09-16）

| 项 | 结果 |
| --- | --- |
| 回测模块重构 | 三个数据集同一协议；主合成数据集用旧排序喂给新代码逐项复现旧结果（差异 0）；新代码按（投产日期、井号）稳定排序，101 口同日投产井分组变化导致 ≤ 0.5 个百分点的变动 |
| 线性流验证队列 | 首版单平板队列产量第 3 年即跌破经济极限、累产超过 EUR —— 改为改造区 + 外围基质复合解并加 1–3 个月起始偏移；参数只按寿命与累产占比选定（寿命中位约 19 年、前 72 个月占 EUR 约 68%） |
| 线性流队列回测（330 口） | EUR 中位误差：Arps 226% / 84% / 48%，物理约束（类比先验）15% / 12% / 9%；高估 >20%：Arps 约 72%–75%，物理约束 13% / 10% / 4% |
| NDIC 真实井（101 个月报、161 万行，选出 5225 口，抽样 800 口） | 24 月产量中位误差：Arps 52% / 42% / 36%，物理约束 27% / 33% / 31%；高估 >20%：Arps 56% / 34% / 22%，物理约束 31% / 21% / 14%；两者绝对误差都在 30% 左右、长期偏低，受人为操作影响 |
| Item 1203 披露草稿 | `services.unit_pud_disclosure` + `/unit/pud-disclosure` + 类别跟踪页面板 + 报告第八章附节；数字与 PUD 滚动一致、引用条款均在条文库中（测试覆盖） |

审查中发现并修正：回测模块说明文字里的英文引号导致模块无法导入 —— 首次"重构前后一致"的核对其实读的是旧结果文件，已作废重做。
