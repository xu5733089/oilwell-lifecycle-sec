# 第二阶段开发计划：证实储量类别跟踪、折耗与减值、指标锚点配置、数据导入

> 延续 `docs/dev-plan-sec-unit.md` 的架构约束：全部数值只从 `src/api/services.py` 出；
> 纯计算放 `src/sec/`、`src/reserves/`，不读库；智能体工具一律只读。
> 数据仍为合成轨道，新增的业务表都同时提供导入通道，真实数据到位后无需改代码。

## 1. PDNP / PUD 动态跟踪

### 1.1 口径

| 类别 | 判定 | 储量取值 |
| --- | --- | --- |
| PDP | 老井近 3 个月有产量；本期新井；措施 | 沿用新-老-措构成 |
| PDNP | 老井近 3 个月无产量，且停产不超过 `pdnp.max_shut_in_months`（24 个月） | 停产前数据逐井递减拟合，从停产时点续算到经济极限；剩余可采的净收入须覆盖复产费用 |
| 长停井 | 停产超过 24 个月 | 不计入证实储量（如实列出） |
| PUD | 部署井位未钻；半径 `pud.radius_m` 内当期在产井不少于 `pud.min_producing_neighbors` 口（连续性）；计划钻井时间不晚于首次入账后 5 年，且当期未超过 5 年期限（五年规则）；单井储量净收入覆盖钻完井投资（经济性） | 单元老井类型曲线 × `pud.certainty_factor`，截到经济极限 |

井位各项判定都保留原因（已入账 / 连续性不足 / 超五年 / 不经济 / 已钻），界面与报告如实列出。

### 1.2 对账

- PDP 对账"类别调整"行不再固定为 0：
  **PDNP 复产转 PDP** = 复产井期末储量 + 本期产量；**PDP 停井转出** = −（停井井期初储量 − 本期产量）。技术修订仍为轧差项。
- 新增证实储量类别滚动表：PUD 期初 → 转为 PDP（本期钻井）→ 五年规则移出 → 其他移出 → 修订 → 新入账 → 期末，
  以及 **PUD 转化率**（本期转化井位数 / 期初 PUD 井位数）与临近五年期限的预警；PDNP 期初 → 复产 → 新增停井 → 长停移出 → 修订 → 期末。

### 1.3 合成数据

- 在产老井以独立随机数流按比例插入一段 4–14 个月的停井，复产后接续原递减（让 PDNP 复产有数据）。
- 新表 `unit_location`（部署井位）：已钻井位关联本期提采新井；另生成未钻井位，含合规、连续性不足、超五年、计划超五年等情形。

## 2. 折耗额与减值测试

- 新表 `unit_asset_book`：单元 × 期间的期初资产净值（可空，空则由上期期末滚动）与本期资本化投入（万元）。
  合成轨道按单井钻完井投资与措施费用生成，真实轨道从财务台账导入。
- 产量法折耗率 = 本期产量 /（期末证实已开发储量 PDP + PDNP + 本期产量）；
  折耗额 =（期初净值 + 本期投入）× 折耗率。
- 减值测试：可收回金额 = 减值测试价下证实已开发储量的未来净现金流折现值（单元指数递减剖面，折现率、汇率见配置）；
  减值额 = max(0, 折耗后账面价值 − 可收回金额)。
- 简化与局限写进返回体：不含 PUD 未来投资与弃置费，剖面为单元级指数递减。

## 3. 指标锚点可配置

- 新表 `indicator_profile`：方案 id、名称、说明、锚点 JSON、是否内置、是否默认。
  内置"致密油水平井（示例）"来自 `conf/indicators.yaml`，另内置"常规注水油田（示例）"。
- 服务：列出 / 读取 / 保存（校验优值≠差值、权重≥0）/ 删除自定义 / 设为默认 / 未保存锚点的实时预览。
- 运行监控可切换方案；报告与问答注明所用方案。配置写入走 HTTP、记审计日志，不注册为智能体工具。

## 4. 数据导入

- 统一导入框架 `src/ingest/imports.py`，三种类型：产量与工作量计划、单元资产账面价值、PUD 部署井位。
- CSV（UTF-8 / GBK）与 Excel；中英文表头均可；提供模板下载。
- 先预检（缺列、类型、未知单元、重复键、负值、年月格式、与实际偏差过大的提醒），无错误才能确认导入。
- 按主键替换并记批次（`import_batch`，保存被替换的旧值），支持撤销最近一次导入。
- 前端上传以 base64 JSON 提交（不引入 python-multipart 依赖）。
